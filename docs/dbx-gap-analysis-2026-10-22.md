## 最新 DBX 变化的适用性

本轮 [46 个上游提交](https://github.com/t8y2/dbx/compare/eeab128d738e59bbc4bd16646998275b921e16d2...b160d130560f71c5c429be15cec6147f677a4b3a) 不等于 46 个本项目缺陷。

| 上游变化 | 对 Oxide 的判断与落点 |
| --- | --- |
| MySQL 连接池 checkout 使用用户配置的超时（`ed9804ffa`） | Oxide 的初始及 schema pool 都固定为 30 秒，见 `drivers/mysql/driver.rs`、`runtime.rs`。这是可配置超时的优化方向；当前 SQL 连接配置没有对应字段，不能描述成“已有设置被忽略”。纳入 G01/G02/E03。 |

| Oracle 流式导出用 ROWNUM 分页、Kingbase 权限/identity 降级（`6d529b136`、`234e5c64d`、`7ea403146`） | 属于 G01/G05/G06 的产品契约，不应直接复制到 PostgreSQL/MySQL 通用实现。 |
